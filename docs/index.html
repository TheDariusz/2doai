Overview Architecture

Overview implemented

2do AI is a personal AI-powered todo + planning app: three task layers (current, long-term, dreams) across 11 life domains, with proactive natural-rhythm reminders. Solo-dev, after-hours MVP.

The repo holds two independent projects — no monorepo tooling, each builds from its own directory:

StackRole
backend/Spring Boot 4, Java 25, Maven, PostgreSQL 18 (JPA/Hibernate + Flyway)REST API, auth, AI orchestration, background jobs
frontend/React 19, Vite, TypeScript (strict), PWASPA consuming the REST API

Where things live

context/foundation/Design docs: PRD, roadmap, data model, auth session model, deployment runbook
backend/src/main/resources/db/migration/Flyway migrations (schema owner; Hibernate runs ddl-auto=validate)
.github/workflows/CI/CD (see the CI/CD section)

These docs are for developers. A separate user-facing document will exist later.

Architecture

Current implemented

Pattern B — unified origin: Cloudflare Pages serves the static frontend and reverse-proxies /api/* to the Fly.io backend, so production is same-origin and needs no CORS. Sessions are server-side cookies held in-memory on the single Fly machine (not JWT, never DB-backed — a per-request session SELECT would defeat Neon autosuspend).
